# Project specification

## 研究背景

低带宽视频会议需要在有限传输预算下维持可理解的口型、自然的说话人外观和音画同步。音频与嘴部运动存在跨模态相关性：音频可预测部分基础发音运动，但不能完整解释说话人个体差异、视觉上下文和预测误差。

本项目研究“音频预测残差驱动的嘴部语义稀疏传输”：接收端从音频预测嘴部运动，发送端只传输音频无法准确预测且对重建重要的运动残差，并用参考人脸生成视频。

## 实际应用场景

目标场景是带宽受限、但音频仍可用的视频会议。研究原型关注表征、选择、信道鲁棒性和重建质量之间的关系，不构建可部署会议系统，也不实现完整协议栈。

## 研究链路

```text
音频 ──> 音频到运动预测器 ──> 预测嘴部运动 ───────────────┐
视频 ──> 运动提取器 ────────> 真实嘴部运动 ──> 残差 ──> 选择/JSCC/AWGN
                                                           │
参考人脸 + 预测运动 + 恢复残差 <───────────────────────────┘
                    │
                    └──> 生成式视频重建与评价
```

## 算力约束

- 长期资源按约两张 RTX 3090 规划，可按需租借云 GPU，但上限未确认。
- 不从头训练大型生成模型。
- 优先冻结的预训练模型、离线特征、小型 GRU/TCN/Transformer、MLP JSCC。
- 第一轮所有基础检查应能在 CPU 上运行。

## 数据约束

- 不自建数据集；优先使用 GRID，后续候选数据集需另行评估许可和适用性。
- 不自动下载完整数据集，不将数据或派生产物提交到 Git。
- 数据划分按说话人隔离，防止身份泄漏。
- 首轮数据实验应支持单个说话人的少量视频，以控制验证成本。

## 当前研究假设

1. 音频特征能够预测足以作为重建先验的低维嘴部运动。
2. 预测残差比完整运动含有更少的必要传输信息。
3. 残差幅度或任务重要性选择能优于随机与固定位置选择。
4. SNR 和带宽预算可用于动态调整传输残差数量，提高跨信道稳定性。

上述内容均为待实验验证的假设，不是论文结论。

## 暂不考虑

- 强化学习、扩散视频模型和多模态大模型；
- 大型生成模型的从头训练；
- 自建数据集；
- 完整调制、编码、LDPC、OFDM 或传统协议栈；
- AWGN 以外的复杂信道（第一阶段）；
- 在基线稳定前引入高成本或难以消融的模块。

## 预期研究贡献

以下是候选贡献，需由实验结果确认：

1. 一条从公开数据、运动提取、音频预测、残差选择到重建评价的可复现实验链路。
2. 对完整运动与音频预测残差在码率—质量权衡上的系统比较。
3. 一个可独立关闭并消融的信道感知残差重要性选择模块。
4. 在不同 SNR 和带宽预算下的重建稳定性分析。

## 尚未确认的风险

- GRID 的受控语句和正面人脸能否代表目标会议场景。
- 何种运动表示最适合音频预测、稀疏传输与生成式重建三者。
- 第三方运动提取/重建模型的许可证、权重可用性和接口稳定性。
- 低维运动误差是否能稳定映射为感知视频质量和音画同步变化。
- 码率定义、传输预算和跨方法公平比较方式尚需在基线前锁定。
- 可用 GPU 时间和存储预算尚未量化。
