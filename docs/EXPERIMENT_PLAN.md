# Experiment plan

## 总体原则

每一阶段只有在输入、输出、配置、评价和失败记录可复现后才进入下一阶段。每次正式运行保存解析后的配置、Git commit、随机种子、环境、日志、结果 JSON 和产物引用。数据按说话人隔离，所有基线使用相同划分。

## E0：仓库与复现基础设施

- 目标：建立 Python 包、YAML 配置、路径约定、质量检查和研究文档。
- 验收：`make lint`、`make test`、`make smoke` 通过；仓库不含数据、权重或实验输出。
- 状态：本轮交付。

## E1：GRID 小子集数据管线

- 输入：用户手动获取的 GRID 数据，先使用一个说话人的少量视频做管线验证。
- 处理：探测元数据、拆分/引用音频、裁剪人脸、提取音频特征和关键点；已有输出默认跳过。
- 输出：manifest，至少含 `sample_id`、`speaker_id`、`video_path`、`audio_path`、`fps`、`sample_rate`、`frame_count`、`split`，另含失败记录。
- 验收：管线可重复运行，第二次运行不覆盖有效产物；正式划分按说话人隔离。
- 状态：已完成；真实 `s1` pilot 为 20 条样本、1,500 帧，处理和验证失败数均为 0。

## E2：运动提取与重建敏感性基线

- 输入：参考人脸、真实视频和真实运动表示。
- 方法：统一运动提取/重建适配器；对运动添加高斯噪声、均匀量化、随机丢弃和固定比例稀疏化。
- 输出：重建样例、运动误差和视频质量结果。
- 验收：第三方组件缺失时明确失败；mock 测试通过；不宣称未运行模型已集成。
- 状态：已完成 pilot 验收；固定 LivePortrait 后端提取 18 维嘴部表情运动，
  20 条 `s1` 样本的 28 个条件共生成 560 条指标记录，失败数为 0。

## E3：音频到嘴部运动基线

- 输入：log-Mel 特征和时间对齐的运动表示。
- 比较：静态平均嘴型、上一帧嘴型、GRU（首选简单基线；TCN/轻量 Transformer 仅在必要时比较）。
- 损失：首轮 L1 或 L2；速度和平滑约束后续作为可关闭项。
- 指标：Landmark L1/L2、NME、Temporal Velocity Error；同步指标为可选 `TODO`。
- 验收：按说话人测试，输出逐基线和逐说话人的结果。
- 状态：首次三说话人可行性运行的 train/validation/test 分别为
  `s3` 99 条、`s1` 99 条、`s2` 100 条；三个种子的 validation 原始运动 L1
  为 `0.001775 ± 0.000058`，仅比 `train_mean` 的 `0.001780` 低约 0.30%。
  test L1 为 `0.002529 ± 0.000106`，优于 `train_mean` 的 `0.002655`，但差于
  `zero_motion` 的 `0.002149` 和不可部署的 `oracle_persistence` 的 `0.000615`。
  全量冻结 LivePortrait 重建覆盖 199 条 validation/test 样本、1,194 条结果，
  失败数为 0。后续审计发现该运行将 1.12–2.50 秒的 `audio_25k` WAV 整体插值
  到三秒视频，因而这些模型数值不得作为 RQ1 证据。已改用 MPG 内嵌同步音轨和
  严格时间戳 log-Mel。修正后的 validation/test 三种子运动 L1 分别为
  `0.001674 ± 0.000042` 和 `0.002492 ± 0.000090`，相对 `train_mean` 改善
  5.95% 和 6.15%；但 test 仍比 `zero_motion` 差 15.95%。全量重建再次产生
  1,194 条结果，失败数为 0。E3 工程验收完成，RQ1 只获得有限支持。
  随后扩充到十说话人、每人 100 条：train/validation/test 为 800/100/100，
  对应 8/1/1 个完全隔离的说话人。三种子 validation/test 运动 L1 分别为
  `0.001884 ± 0.000020` 和 `0.001978 ± 0.000065`，相对 `train_mean` 改善
  21.72% 和 7.82%，相对 `zero_motion` 改善 28.90% 和 12.61%。200 条
  validation/test 样本的 1,200 条冻结 LivePortrait 重建记录失败数为 0；
  最佳 validation 种子 43 的 test 嘴部 NME 为 `0.02208`，比 `train_mean`
  和 `zero_motion` 分别低约 14.01% 和 13.65%。十说话人 E3 验收完成并通过
  E4 门槛。

## E4：无信道预测残差价值验证

- 定义：`r_t = k_t - k_pred_t`。
- 比较：完整运动、纯音频预测、完整残差、固定预算随机残差、幅度 Top-K。
- 控制：同一预测器、运动表示、重建器和预算统计。
- 验收：绘制率—质量曲线，并报告多种子均值与离散程度。
- 状态：十说话人运动空间分析已完成。固定 validation L1 选择的 seed 43，
  200 条 validation/test 样本共产生 6,600 条结果。test 上纯预测 L1 为
  `0.001893`；原始幅度 Top-K 在 `K=4/18` 时降至 `0.000785`，并保留约
  82.3% 的原始残差能量，优于同预算随机选择的 `0.001471`。归一化幅度
  Top-K 同预算为 `0.001203`，说明训练标准差会显著改变选择结果。
  冻结 LivePortrait 全量重建评价也已完成：validation/test 各 100 条，
  每条 23 个条件，共 4,600 条结果，失败数为 0。test 上纯预测相对 lip-only
  oracle 的嘴部 ROI MAE/NME 为 `5.299/0.02195`；原始幅度 Top-K 在
  `K=4/18` 时为 `2.100/0.00789`，分别改善 60.4%/64.0%，并明显优于三种
  随机掩码均值 `4.852/0.01913`。完整残差与直接使用真实运动逐像素一致，
  关键点检测覆盖率为 100%。这些是发送端已知真实残差的 oracle 上界，不是
  已实现的选择器、压缩码率或信道结果。

## E5：AWGN 与轻量 JSCC

- 方法：只编码低维运动残差，使用小型 MLP、逐样本平均复数符号功率归一化和
  Sionna PHY 2.0.1 复数 AWGN。
- 条件：训练 SNR 与测试 SNR 分离；首批测试为 -5、0、5、10 dB。
- 验收：功率约束和形状测试通过；报告各 SNR 的运动/视频质量。
- 状态：正式 Sionna GPU 训练及运动空间 test 已完成。12 个模型和 15,800 条
  test 指标无失败。0/5/10 dB 的运动 L1 均优于纯预测，`C=4,10 dB` 改善约
  46.4%；训练范围外 -5 dB 全部退化。5 dB 虽降低位置 L1，却增加速度误差，
  表明存在时间抖动。正式协议使用每有效非参考帧 `1/2/3/4` 个复数信道符号，
  不能将 `C/18` 误称为真实 bitrate。冻结 LivePortrait 视频评价也已完成：
  100 条 `s7` test 样本、每条 22 个条件，共 2,200 条指标，失败数为 0。
  相对纯预测，`C=4,10 dB` 的嘴部 ROI MAE/NME 分别改善 27.9%/34.6%；
  `C=4,-5 dB` 则分别恶化 34.7%/32.4%。E5 工程与真实 GPU 验收完成，结果支持
  高 SNR 下残差 JSCC 的可行性，同时明确要求下一阶段加入低 SNR 不发送门控。

## E6：信道感知残差重要性选择器

- 输入：预测残差、音频摘要、SNR、预算，可选运动速度或不确定性。
- 递进基线：幅度规则、小型 MLP 打分；仅在需要时尝试 Gumbel-Softmax 或可微 Top-K。
- 输出：固定预算 Top-K 或可微门控。
- 消融：每个输入、损失项和模块均可独立关闭。
- 验收：与随机、固定位置、固定比例和幅度 Top-K 在匹配预算下比较。
- 状态：第一阶段 validation-only SNR 安全门控已完成。100 条 `s3` validation
  在与 test 错开的 15 个 SNR、3 个噪声种子上产生 18,100 条记录；四个 `C`
  均冻结阈值 `-1.5 dB`。冻结后在 100 条 `s7` test 上产生 4,800 条有限结果：
  -5 dB 全部回退纯预测，消除了始终发送造成的 4.3%–20.7% 位置 L1 退化，
  同时保留 0/5/10 dB 的 JSCC 收益。第二阶段 hard Top-K scorer 也已完成：
  冻结 E5 后训练 4 个预算、3 个种子的 12 个小模型，test 生成 48,000 条指标，
  dense 复算与 E5 原结果最大差为 0。learned 在 `K=2/4` 下相对原始幅值规则
  跨 0/5/10 dB 平均改善 `4.09%/3.36%`，但在 `K=6/8` 下平均退化
  `1.05%/3.07%`。因此信道感知学习选择只获得预算相关的有限支持；进一步
  超参数或结构选择只能使用 train/validation，不能再根据本轮 `s7` test 调整。
  最小 2×2 validation-only 消融随后将 100 条 `s3` 预先哈希分为 50 条
  calibration 和 50 条 audit，训练 24 个模型并生成 21,000 条 audit 指标。
  关闭 SNR 输入和速度损失后的最佳格仍比原始幅值规则差
  `0.35%（K=6）/2.18%（K=8）`；速度损失只表现为小幅位置—时间权衡。
  因此停止 scorer 超参数搜索，保留其 K=2/4 的有限正结果和 K=6/8 的负结果。

## E6.5：冻结通信代价与率—质量报告

- 口径：75 帧、25 fps、首帧为参考帧；每段有 74 个可传输帧。
- 率轴：`C=1/2/3/4` 分别为每段 74/148/222/296 个复信道符号，不报告未定义的
  bit/s。
- 状态：已完成。报告只读取冻结 E5/E6 汇总和 SHA-256，没有重新选择模型或访问
  test 调参。24 个可发送 sparse 点全部被同速率 dense residual JSCC 支配；
  hard Top-K 降低输入非零维数，但没有降低固定 `C` 下的实际信道符号数。

## E7：完整运动与预测残差的匹配通信对照

- 目标：直接检验 RQ2，在相同 Sionna AWGN、相同 18 维模型规模和相同
  `C=1/2/3/4` 下比较完整运动 JSCC 与冻结 residual JSCC。
- 控制：复用十说话人身份隔离划分、冻结音频预测器、E5 residual 模型和
  LivePortrait；只新增完整运动 JSCC，避免重复已有 GPU 实验。
- 评价：原始运动 L1/RMSE/速度 L1、嘴部 ROI MAE/NME/PSNR/SSIM，以及明确的
  复符号/段和复符号/秒。
- 状态：已完成。完整运动 12 个模型和 15,800 条 test 运动记录均无 NaN 或
  schema/path 错误；100 条 test 的 LivePortrait 评价产生 1,700 条视频指标，
  失败数为 0。冻结比较包含 4,800 个运动配对和 16 个视频组：residual 在运动
  L1 的 16 个组中胜出 14 组，在嘴部 NME 中胜出 13 组。优势主要位于低/中
  SNR 和紧预算；10 dB、大预算时完整运动追平或局部胜出。RQ2 获得有条件支持。

## E8：冻结论文证据包

- 目标：不重新训练 E3–E7 模型，从冻结 CSV/JSON 生成论文正文图、附录图、统一
  主表、逐样本不确定性统计和中文结果章节草稿。
- 输入：E3 十说话人预测、E4 oracle 残差、E5 residual JSCC、E6 门控/scorer、
  E6.5 通信代价和 E7 full-motion 匹配比较的完成产物及 SHA-256。
- 主图：音频预测基线、oracle 残差率—质量、残差 JSCC 运动/视频质量—SNR、
  低 SNR 门控、full-motion 与 residual 匹配对照。
- 统计：E7 以 100 条 test 样本为统计单位；先在样本内聚合噪声实现，再对配对
  方法差值做固定种子 bootstrap，不能把三个噪声实现当作 300 个独立说话样本。
- 定性样本：使用预先固定的排序位置选择低/中/高 SNR 对照，不根据观感重新挑选。
- 产物：`outputs/thesis_evidence/{timestamp}/`，保存解析配置、源哈希、环境、
  Git commit、主表 CSV/JSON、图、图注和完成标记。
- 验收：所有图表可由冻结源一键重建，resume 不改写匹配产物；图注同时说明条件、
  指标方向和边界；Git 只提交小型脚本、配置和文档。
- 状态：已规划，下一阶段。无需 GPU，除非后续明确批准新增的定性视频导出。

## 评价与报告

- 运动：L1/L2、NME、速度误差。
- 视频：具体指标在重建基线确认后锁定，候选指标不得在验证前当作最终方案。
- 同步：候选同步指标标为 `TODO`，需验证实现、适用域与许可证。
- 通信：明确元素数、比特数或信道使用次数的定义，不混用；正式率—质量图前冻结统计口径。
- 统计：正式实验使用固定种子集合，并保存逐样本结果；种子数量和置信区间方案在算力试跑后冻结。
